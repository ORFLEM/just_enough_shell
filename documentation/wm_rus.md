# Инструкция по созданию адаптера WM

- в for-quickshell лежит папка `CustomBar` - это заготовка для адаптера WM
- в заготовке лежат 4 скрипта-заготовки, где вывод уже подготовлен для JES, вам лишь надо ввести команды ipc вашего wm, тип команды - subscribe режим с json выводом  
- эти 4 скрипта-заготовки нужны для передачи данных о воркспейсах, координат для 2d canvas wm, раскладка клавиатуры и активное окно (передавать надо app id).

- Автор принимает PR в ядро, но за тот или иной адаптер, не сделанный автором JES, обязан следить отправивший PR
- Также принимается issue/PR с просьбой-добавлением/прописыванием своего wm в wm_repo, и этот вариант **рекомендован**
- При изменении API подключения автор сообщит всем авторам wm в issues об изменении своего api подключения, если он указан в wm_repo или это адаптер в ядре не от автора JES, в issues будет пояснение к обновлению + новый шаблон

- Заготовка сделана для типовых wm с воркспейсами или координатами, если wm имеет другую систему, сообщите автору в [Issue](https://github.com/ORFLEM/just_enough_shell/issues/new), тогда автор напишет 3-й режим `custom`, который будет выводить текст, т.е. сразу готовый текст
